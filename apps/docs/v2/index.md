# v2 Docs Archive

::: warning Deprecated Line
v2 docs are preserved for existing installations, but new integrations should migrate to v3 provider runtime. See [Migration to v3](/guide/provider-migration-v3).
:::

This archive keeps the v2 usage model available so teams can maintain legacy workflows while planning migration.

## What v2 means in this archive

- Google-first API (`getSpreadSheetData`) as the primary entrypoint.
- Action inputs like `google-spreadsheet-id`, `google-client-email`, and `google-private-key`.
- Legacy sync options such as `sync-local-changes`, `auto-translate`, and `wait-seconds`.
